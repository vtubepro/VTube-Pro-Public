# VTube Pro guides

Every guide, grouped by who it is for. New to VTube Pro? Start with the [Quick Start](QUICK_START.md).

> **Inside the studio:** press **F1** or click **?** in the top bar. The guides marked *in Help* are bundled with the
> studio, work offline and are searchable. Each area also has a small **?** next to its title that opens the right
> section.
