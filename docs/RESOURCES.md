# VTube Pro — external resources, tools & references

Research pass 2026-09-25 (web, view-only; nothing downloaded or installed). VTube Pro ships publicly, so every item is
judged on whether it can go **inside a distributed, commercial-capable product**. Recommendations:

* **adopt**: licence allows shipping it (CC0 / MIT / BSD / Zlib / Apache / CC-BY with a credit line).
* **reference-only**: fine to learn from, but never ship its files or code (NC / ND / SA / proprietary / "no redistribution").
* **avoid**: the licence or terms conflict with what VTube Pro does.

"Verified" means the licence was read on the project's own licence or FAQ page or repo. "Secondary" means the primary
page blocked the fetch (403) and the terms come from the vendor's own help-centre snippets or official quotes via search.
Check those again before shipping.

Already in use (not repeated below): MediaPipe tasks-vision, three r186 + three-vrm 3.5 (MToon), three-mesh-bvh,
RNNoise (Jitsi wasm), Silero VAD v5, onnxruntime-web, the CC0 pixiv VRoid samples in `tools/vendor/vroid`, MPFB2/MakeHuman
CC0 assets, Blender 5.1 headless. Already built (so not listed as gaps): VMC receive and send (`server/tracking/vmc.ts`),
iFacialMocap, the VTube Studio phone protocol and plugin API, generic OSC, YouTube/Kick/Rumble chat, OBS WebSocket
automation, Discord multiplayer with model custody, and the scene engine (rooms, lights, raid, space, town).

### 2.4 Anime face, hair and body references (learning only)

Keep using the sources in `docs/FACE_CREATION.md`. New additions:
* GGXrd GDC 2015 talk, **free** on the Internet Archive (archive.org/details/GDC2015Motomura) and handout PDF
  (ggxrd.com/Motomura_Junya_GuiltyGearXrd.pdf): custom normals, vertex-colour line width, 2D-style frame-held animation.
* **Hi-Fi RUSH GDC 2024 "3D Toon Rendering"** (gdcvault.com/play/1034330; community notes foth.top): SDF face
  shadows independent of normals and blendshapes; stepped toon lights; characters exempt from environment light;
  halftone and hatching with smoothstep AA. All of this applies directly to `toon.ts`.
* **Genshin Impact GDC 2021 "Crafting an Anime-Style Open World"** (YouTube -JFyAdI_rO8): dynamic facial shadow
  texture, pipeline overview.
* akasaki1211/sdf_shadow_threshold_map (MIT, Python/NumPy/OpenCV): builds the threshold map from painted light-angle
  masks. It fits our numpy face_kit.
* NoiRC256/URPSimpleGenshinShaders, kaze-mio Genshin shader (already cited; check each licence before copying code).
* lilToon (MIT): read its docs for feature ideas (rim shade, shadow colour layers, matcap, AngelRing, outline width masks).
  MIT means ported concepts or code are fine with the notice.
* Unity Toon Shader UTS3: **Unity Companion License** (verified). Code may only be used with Unity, so **concepts only**.

## 7. Avoid / licence traps (summary)

* **Bandai Namco dataset (CC BY-NC), LaFAN1 (CC BY-NC-ND), AMASS-family**: non-commercial.
* **XR Animator code (CC BY-NC-SA)**: UX reference only.
* **Mixamo as a shipped or exportable library**: raw-file redistribution is banned, and a creator tool makes files reachable.
* **Sonniss #GameAudioGDC**: no supplying the sounds "as sound effects", "asset pack" or "SDK", and an **explicit AI-training ban**.
  A user-facing SFX library is exactly that. Use Kenney CC0 instead.
* **Live2D Cubism SDK**: Expandable Application licence required, no small-business exemption.
* **VRoid Studio preset meshes/textures in a generator**: separate pixiv licence needed; keep to the CC0 samples (and new
  AvatarSample_A–Z are not CC0).
* **Unity Toon Shader UTS3**: Unity Companion License, Unity-only.
* **Hunyuan3D 2.x**: licence (Tencent Hunyuan 3D Community) excludes the EU, UK and South Korea, adds a >1M-MAU clause, and bans
  using outputs to train other models. Policy (Director decision, 2026-10-16, after users asked for a ComfyUI character maker):
  * VTube Pro **never bundles** the weights (not in the zip, the installer or the repo) and never makes them a default.
  * A person may install VTube Pro's **Character 3D** recipe (ComfyUI's built-in Hunyuan3D nodes, the Comfy-Org repackages) into
    THEIR OWN ComfyUI with **Set it up for me**. The weights are their own download from Hugging Face (pinned revision, SHA-256
    checked), only after their own Yes, and the consent list shows the licence notice (not for the EU, the UK or South Korea) above
    the button (`restricted` in `shared/comfyWorkflows/models.ts`). They are responsible for where they live and for what they make.
  * **AI house rules:** an AI may suggest or use the recipe for props, creatures, mascots and non-human characters. Humans and anime
    humans still come from a proper base (VRoid CC0 samples, `blender/face_kit`): the rule "never Tripo / Meshy / primitives" covers
    Hunyuan3D too. The AI never presses Yes for the user and never offers it to someone who lives in a place the licence excludes.
    One copy of this rule feeds every AI-facing text (`HUNYUAN_AI_RULE` in `shared/comfyWorkflows/models.ts`);
    `tools/hunyuan_policy_unit.ts` fails when the house rules, the instruction pack, the docs and the catalogue disagree.
  * The result is a plain grey shape; the Blender MCP's own `generate_3d` (cloud services) stays off for VTube Pro work.
* **TRELLIS.2**: code and weights MIT, but depends on nvdiffrast/nvdiffrec (NVIDIA licences, historically non-commercial)
  and needs a 24 GB GPU. Server-side experiments only, after checking those dependency licences.
* **AndroidMoCap**: PolyForm Shield ("no competing product"). Interop over protocols only.
* **Poly Pizza non-CC0 items**: CC-BY items need per-model credits; NC/ND variants exist.
* **UniRig / SkinTokens (ML auto-rig)**: code and weights are MIT, but both repositories vendor the Michelangelo shape encoder (GPL-3.0
  upstream), UniRig downloads Meta's `facebook/opt-350m` config (OPT-175B licence: non-commercial research), and the training data is
  Objaverse / VRoid Hub / ModelsResource. Optional, offered to every user and installed on their click (owner decision 2026-10-24), with the licence facts as a short note: `docs/AUTORIG_3D.md`. **Make-It-Animatable**:
  trained on Mixamo characters, out.
* **Mesh2Motion**: assets repository CC0-1.0, but skip `3d-models/CC-SA/` and `motion-capture/` (source of the captures not stated).
